| Property | SPL2000 manufacturer reference |
| --- | --- |
| Function | Active Class B AIS/VHF antenna splitter, sharing one VHF antenna with AIS transponder and VHF radio; optional AM/FM radio feed |
| Nominal DC supply | 12 V or 24 V DC |
| Published input-voltage range | **9.6–31.2 V DC** |

| Power-lead colour convention | Red = DC positive; black = DC negative (manual, not verified on boat) |
| RF connectors | VHF antenna and VHF radio via PL259/SO239 coax connectors; AIS transponder via BNC coax connection (manual) |
| RF port impedances | 50 Ω for AIS, VHF and antenna; 75 Ω for optional FM port |
| VHF input power limit | 25 W maximum |
| AIS input power limit | 12.5 W maximum |
| Enclosure | Water resistant; install below deck in a dry location |
| Compass clearance | 0.5 m minimum (per manual) |
| Loss-of-power behaviour | Manufacturer states VHF-to-antenna path remains available on splitter failure or loss of supply |
