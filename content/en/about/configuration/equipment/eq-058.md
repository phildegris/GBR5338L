## Electrical and RF reference

**Owner-confirmed cable and route:** Ancor marine-grade **white RG213 (50 Ω) coaxial cable**, running inside the mast, entering the deckhead through a swan-neck pipe and continuing to the SPL2000. Ancor specifications: **10.3 mm** nominal OD, **96%** tinned-copper braid and **1.9 dB/100 ft at 100 MHz** (catalogue reference, not measured on Ragtime). **No intermediate connectors or joints (owner-confirmed).** The owner estimates **cable length = mast height + 3 m**, not an actual cable measurement. **Both end connectors are soldered PL-259s** (owner-confirmed). Physical condition, solder-joint inspection and weatherproofing have not been independently checked; no SWR readings have been taken.

### Installed model: Vesper Marine VA159 (owner-confirmed)

The owner identifies the installed antenna as the **Vesper Marine VA159**, designed for a shared marine VHF radio and AIS transponder. The following are *published manufacturer-model specifications*, **not Ragtime measurements**:

| Characteristic | Published VA159 information |
| --- | --- |
| Design | Shared AIS and marine voice-VHF antenna |
| Centre frequency | 159 MHz |
| Intended band | 156–162 MHz (approximately 6 MHz bandwidth) |
| Published VSWR | Below 1.5:1 across 156–162 MHz |
| Antenna type | Half-wave |
| Published gain | 3 dBi |
| Antenna form | 1.0 m replaceable 316 stainless-steel whip; ABS housing |
| Connection | SO-239 base socket; detachable coax cable |
| Mounting | L-bracket; suitable for masthead mounting |

**Identification:** VA159 is the confirmed installed model, distinct from Vesper’s AIS-only optimised VA162. The VA159 is explicitly specified for shared voice VHF and AIS service.

The Digital Yacht SPL2000 supports **156–163 MHz** VHF/AIS frequency operation (splitter specification). This figure **does not establish the exact antenna frequency response**. AIS channels use approximately 162 MHz; check antenna match and standing-wave ratio there, as well as voice-VHF frequencies, when the antenna model and test method are known.

## Operational reception observations

- **Owner report:** Following installation of the lower-attenuation Ancor RG213 feeder, reception improved markedly relative to the preceding arrangement.
- **Practical example:** Ragtime has received **Jersey Coastguard transmissions while in Weymouth Bay**.
- **Evidence classification:** Qualitative, owner-reported reception performance. The observation is consistent with a more effective antenna/feed system but does **not** establish the cable's exact insertion loss, the transmission distance, a quantified sensitivity improvement or the antenna's SWR. VHF propagation, transmitting-station characteristics, antenna height and other installation changes can all affect received signal strength.
